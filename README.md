# GitHub_Tools_Software_Engineers
هذا المشروع يهدف إلى استكشاف واستخدام أدوات GitHub الحيوية بالنسبة لمهندس البرمجيات. سيتم في هذا التقرير تقديم شرح مفصل لكل أداة، بدءاً من التحكم بالإصدارات، الفروع، طلبات السحب، وحتى أدوات الأتمتة مثل GitHub Actions. الهدف هو تزويد المهندسين بفهم عميق وأمثلة عملية تساعدهم في تحسين إدارة المشاريع البرمجية
